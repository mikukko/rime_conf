# VSCode 编辑 Rime 词典指南

## 配置说明

已为您配置了 `.vscode/settings.json`，确保在编辑 Rime 词典文件时使用正确的格式。

## 关键配置

1. **Tab字符设置**：
   - `editor.insertSpaces: false` - 按Tab键时插入真正的Tab字符，而不是空格
   - `editor.tabSize: 8` - Tab显示宽度为8个字符，让Tab和空格区别更明显
   - `editor.renderWhitespace: "all"` - 显示所有空白字符

2. **文件关联**：
   - `*.dict.yaml` 和 `*.schema.yaml` 文件自动识别为YAML格式

## 如何正确添加词典条目

### 方法1：使用代码片段（推荐）
1. 在词典文件中输入 `dict` 然后按 `Tab`
2. 会自动生成：`词条	编码	10`（注意是Tab分隔）
3. 依次填入您的词条、编码和权重

### 方法2：手动输入
1. 输入词条
2. **按Tab键**（不要按空格键）
3. 输入编码
4. **按Tab键**
5. 输入权重（通常是10）

## 视觉提示

配置后，您会看到：
- **Tab字符**显示为 `→` 符号
- **空格字符**显示为 `·` 符号
- 状态栏会显示当前使用的是Tab还是空格

## 检查现有条目

如果您发现某个词条不生效，检查：
1. 词条和编码之间是否使用了Tab字符（显示为 `→`）
2. 编码和权重之间是否使用了Tab字符
3. 如果看到的是空格符号（`·`），需要替换为Tab

## 快速替换空格为Tab

如果您已经用空格分隔了词条，可以：
1. 选中有问题的行
2. 使用查找替换（Ctrl+H / Cmd+H）
3. 在"查找"框中输入多个空格（比如 `  `）
4. 在"替换"框中按Tab键输入Tab字符
5. 点击"全部替换"

## 重新部署

修改词典后，记得重新部署Rime：
```bash
"/Library/Input Methods/Squirrel.app/Contents/MacOS/Squirrel" --reload
```

或者在输入法菜单中选择"重新部署"。
